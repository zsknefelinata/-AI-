# 基于 AI 的路面病害智能检测与低碳养护系统（前端 Web 业务系统）

面向县乡道路养护管理人员的业务系统，覆盖「上传 → 识别 → 量化 → 决策 → 报告」闭环：

- 工作台：今日任务、待复核、病害分布、低碳效益与风险提示
- 任务管理：建任务、批量上传影像、状态流转与审计
- 智能识别：原图 / 增强 / 掩码叠加三段展示，逐条确认或标记误检
- 量化评估：相机参数、画面标尺、无标定三种模式，病害长度 / 面积 / 等级人工修正
- 低碳决策：参数实时重算碳排，方案比选并生成推荐理由
- 统计看板：病害、路段、复核与工艺方案图表汇总，明细可导出 CSV
- 报告中心：巡检 / 低碳养护 / 总结模板，生成队列与 PDF / Word 下载
- 系统设置：养护工艺、排放因子、模型版本与审计日志

## 技术栈

- Vue 3 + Vite + TypeScript
- Vue Router 4 + Pinia 2
- Element Plus
- ECharts 5
- lucide-vue-next
- vite-plugin-mock（全部数据本地模拟，不接真实后端）

## 本地运行

```bash
npm install
npm run dev
```

开发地址默认为 `http://localhost:5173/`。

## 质量检查与构建

```bash
npm run type-check
npm run build
```
